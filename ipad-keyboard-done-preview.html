iPad keyboard “Done” button — reference patterns

When a numeric / decimal keypad is shown on iPad, there is no Return key to dismiss it. Apps add a way to close the keyboard. Below are the three real patterns you'll see across apps (Wise, Revolut, PayPal, Cash App, Apple Wallet, etc.), reproduced faithfully to the iPadOS look.

On iPad, the system itself often places a hide-keyboard key (keyboard icon with a down chevron) in the bottom-right of the tray. It's provided by iPadOS — you don't build it. Apps still add Pattern A/B for clarity.

Which one is in your screenshot?

  • Pattern B — the floating “Done” pill. That's what your Wise-style screenshot shows: a rounded grey button hovering above the keypad, on the trailing side.
  • Pattern A is Apple's recommended approach (toolbar “Done”), and is what most banking/fintech apps use on forms with multiple fields.
  • Pattern C is the OS-level key — always available on iPad regardless of the app.
